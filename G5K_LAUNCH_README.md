# Presetup
1. Search for "randerer" and replace with your g5k username
2. Search for "home/" and add your g5k username to store data in network file system

## G5K Custom Environment
1. Refer to the standard method to create a custom environment for G5K
2. Using `border_setup_kadeploy.sh`, configure your environment
3. Refer to the standard method to save your custom environment
4. Use `border-custom-environment.yaml` for the name of the custom environment yml OR adjust the name in `launch_experiments.sh` accordingly

# Usage

1. Configure `launch_experiments.sh` for your experiments
2. Run `launch_experiments.sh` in G5K frontend to schedule your experiments
